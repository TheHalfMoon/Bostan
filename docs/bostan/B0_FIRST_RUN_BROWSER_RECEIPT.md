## Reproduce (disposable localhost database only)

Start the full source runtime from B0-06 in an isolated HOME and confirm health is OK. Then run:

```bash
BOSTAN_E2E_URL=http://127.0.0.1:3100/ \
BOSTAN_E2E_CONFIRM_TEMP_DATA=1 \
pnpm test:bostan-onboarding-browser
```

The script requires a compatible Playwright Chromium download (the test Mac used the optional `BOSTAN_PLAYWRIGHT_EXECUTABLE` override to select an already installed cached binary). It **creates a test organization**; only run it on disposable instances.
