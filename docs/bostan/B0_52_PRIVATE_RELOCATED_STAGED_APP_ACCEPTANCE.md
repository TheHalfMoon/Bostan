## Source-controlled addition

`scripts/bostan-private-staged-full-app-acceptance.sh` now supports a second **explicit** mode:

```bash
bash scripts/bostan-private-staged-full-app-acceptance.sh --run-relocated
```

- Preserves no-argument/`--plan` read-only behavior and the prior fully qualified `--run` path.
- Builds frozen pnpm dependency closure and compiled Bostan server and production Vite UI entirely from local offline cache; copies the source-owned DB schema/migration, adapter helper, and runner vendor assets; creates an **invocation-owned** production pnpm stage with lifecycle scripts disabled.
- Repairs only the previously qualified generated pnpm self-link. Verifies the original staging deployment including all direct production dependencies and internal symlinks.
- With `--run-relocated` only, generates a **second fresh, system-root-constrained** temporary directory; removes only the new empty placeholder and **moves** the deployed package there on the same filesystem. Asserts the original location is absent, re-runs the complete private stage verifier, and confirms the relocated production Vite `ui-dist/index.html` remains present.
- Runs real `node --conditions=bostan-compiled` **from the relocated deployed stage**, including actual compiled SQL migrations on newly initialized isolated PostgreSQL and source-owned HTTP readiness/privacy checks, compiled HTML and hashed JS module delivery, and genuine Playwright Chromium first paint with all external browser requests blocked.
- The existing EXIT trap tracks the *new* stage path so the relocated package is deleted after acceptance or a subsequent test failure. No user-supplied destination path, recursive deletions outside trusted temp roots, cloud model providers or installation to HOME.

Two distinct machine-readable markers `BOSTAN_PRIVATE_STAGED_RELOCATION_VERIFIED` and `BOSTAN_PRIVATE_STAGED_RELOCATION_ACCEPTANCE_PASS` avoid overstating the prior unrelocated `--run` scenario.
