## Verified product discrepancy

The previous B6-13/README generation told users to execute a Bostan company import with --dry-run, despite the shipped isolated Bostan CLI preview deliberately rejecting all such import commands. The inherited CLI codebase contains a different company import implementation, but it is NOT the executable exposed by the private Bostan preview, and it must not be advertised as deployed functionality.

The UI now honestly recommends only the newly implemented read-only inspection of a **downloaded local ZIP**:

    bostan company inspect <local-export.zip>

The README explicitly says this validates archive integrity and that applying/importing a company into an instance is NOT yet supported by this private CLI preview. This is not an API import preview, database collision/authority check or live import.

## Implemented real function

- Dependency-free pure Node ZIP validator that accepts only the STORE/UTF-8/no-descriptor layout generated by Bostan's actual browser-side createZipArchive. It matches local/central entry names, sizes, offsets and CRC32 payload checksums, checks exact root consistency and rejects duplicate, traversal, backslash, malformed, encrypted, compressed, ZIP64 and excessive-size entries.
- Hard admission budgets: 64 MiB total archive, at most 2,000 entries; larger valid exports are **not inspectable with this preview** until separately qualified. No decompression, network fetch, extraction, arbitrary file writing, shell commands, provider calls or database modifications.
- Refuse local symbolic-link input paths and detect file substitutions using device/inode comparison between lstat and fstat. Refuse remote URLs and bad extensions. File-not-found and unsafe-path error messages avoid echoing private input paths.
- JSON output includes only total file count/bytes, limited categorical counts, README presence and the fact that supportedForImport=false. It never prints file names, archive root, actual file body, ZIP input path or raw secrets.
- Expose through the Bostan private preview CLI, and include the new helper in both built dist and the integrity-hashed isolated local installer payload. A change to the installed helper invalidates read-only status instead of silently continuing.
- Original legacy protocol, datastore import API and legally necessary upstream attribution untouched. Legacy import operation in this CLI preview remains explicitly disabled.
