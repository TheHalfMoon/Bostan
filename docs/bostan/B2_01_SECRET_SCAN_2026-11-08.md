### Note on the eval evidence file
`server/src/services/connectors/slack/evals/2026-10-08-evidence.json` contains real-looking Slack channel IDs and timestamps from upstream evaluation data. These are not credentials. Consider removing or synthesising this file before any public release, because it is inherited operational data.
