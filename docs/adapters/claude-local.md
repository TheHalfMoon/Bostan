# Local agent adapter boundaries

Bostan is **not release-qualified**. The inherited claude_local adapter identifier is a compatibility detail, not proof that a safe zero-cost local agent or model is installed.

**Do not enter API keys, credentials, or tokens. No paid providers or services.** Do not sign into subscriptions, install a paid CLI, activate remote models, bypass interactive permissions, or start an autonomous agent from this guide.

A provider adapter can execute processes and expose files, network access, environment variables, transcripts and credentials. Such effects require explicit scoped consent, enforced sandbox boundaries, cancellation tests, redaction and installed cross-platform verification. A compatibility setting such as dangerouslySkipPermissions does not grant permission to bypass controls.

Only synthetic, owner-marked offline QA is in scope. The first genuinely zero-cost offline agent, governed tool effects, Linux rootless Bubblewrap, Windows/macOS/Linux installed behavior, credential isolation and legal LICENSE/NOTICE/provenance are not yet qualified. No adapter activation or installation commands are provided. **NO-GO**.
