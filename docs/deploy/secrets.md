# Secrets and credential safety

Bostan is **not release-qualified**. This is a private engineering preview, not a secret setup or agent activation guide.

**Do not enter API keys, credentials, or tokens. No paid providers or services.** Never copy real user or customer secrets into a repository, chat, agent environment, test fixture or log.

The inherited source contains secret-reference and encryption interfaces, but no navigable document can certify installed encryption, master-key custody, tenant isolation, rotation, backup recovery, plaintext logging protection, or agent-side effects. Internal compatibility names such as PAPERCLIP_SECRETS_MASTER_KEY, PAPERCLIP_HOME, PAPERCLIP_API_KEY and secret_ref are not supported Bostan setup instructions.

Before any credential-enabled qualification, prove synthetic-only secret lifecycle, storage permissions, user and tenant authorization, redaction, process environment disclosure, fail-closed missing bindings, and installed Windows/macOS/Linux behavior. AWS, external vaults, subscriptions, hosted services and real credentials are excluded from this zero-cost private QA scope.

No setup, migration, key injection or provider onboarding command is authorized here. Original upstream legal LICENSE/NOTICE/provenance must remain intact. Release **NO-GO**.
